# rock

A tiny Android app that locks your distracting apps behind a rock — any NFC tag you keep somewhere else.
Tap the rock to lock. Tap it again to unlock. It can also wake you up: the alarm only stops when you tap the rock.

Hand-drawn, two greys, Paleolithic mood. Inspired by [Brick](https://getbrick.com).

## Download

**[⬇ rock.apk](https://github.com/cemtatli/rock/releases/latest/download/rock.apk)** (~2.4 MB, Android 10+, needs NFC)

Install it on your phone (allow "install unknown apps" for your browser or file manager), then open **rock**.

> The APK is signed with a development key. It is for testing, not a store build.

## Setup

1. Open the wheel (top right) and give the permissions:
   - **nfc**: to read the rock
   - **accessibility**: to close blocked apps. If the switch is grey: App info → ⋮ → *Allow restricted settings*.
   - **notifications** and **full-screen alarm**: so the alarm can ring over the lock screen
2. Hold any NFC tag (sticker, transit card, hotel key…) to the back of the phone. That is your rock.
   You can add more rocks, name them and remove them under **rocks**.
3. Pick the apps to block under **apps**.

## How it works

- **Lock / unlock:** tap a paired rock on the main screen. While locked, opening a blocked app shows a "sleeping" screen instead.
- **Alarm:** one daily time. It rings until a paired rock is tapped.
- **Run away:** lost your rock? While locked you get 3 emergency unlocks (hold the button for 5 seconds).
- Nothing leaves the phone. The accessibility service only reads which app is in front. Tag IDs are stored as SHA-256 hashes.

## Build

```sh
./gradlew :app:assembleRelease   # app/build/outputs/apk/release/app-release.apk
```

Kotlin + Jetpack Compose, no other dependencies. `minSdk 29`, `targetSdk 36`.

Drawings and icons are generated by `design/doodle.py`:

```sh
python3 design/doodle.py app/src/main/res /tmp/preview.png
```
